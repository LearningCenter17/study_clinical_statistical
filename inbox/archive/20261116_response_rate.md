## 先说"应答"

在临床试验里，**应答（response）**指病人用药后，病情改善达到了**事先规定的标准**。每个病人最后只有两种结果：**应答（1）** 或 **未应答（0）**。

不同疾病的应答标准不一样：

| 领域 | 应答标准举例 |
|---|---|
| 实体瘤 | RECIST 评估为 CR（完全缓解）或 PR（部分缓解） |
| 类风湿关节炎 | ACR20：关节症状改善 ≥ 20% |
| 银屑病 | PASI 75：皮损评分改善 ≥ 75% |
| 抑郁症 | 量表评分较基线下降 ≥ 50% |

在 ADaM 里，应答结果一般存在 **ADRS** 数据集中，用 `AVALC = "Y"/"N"` 或 0/1 表示。前面模拟数据里的 `RESP` 列就是这个。

## 应答概率

**应答概率**是指：一个病人用了这个药之后，**发生应答的可能性有多大**。

比如说 Drug 的应答概率是 45%，意思是：如果有很多符合条件的病人都用这个药，大约 45% 的人会应答。

它和前面讲的 μ、σ 一样，是**总体的真实值**：

| | 真实值（总体） | 估计值（样本） |
|---|---|---|
| 符号 | **p** | **p̂**（p-hat） |
| 含义 | 这个药对这类病人的真实应答概率 | 试验里实际观察到的应答率 |
| 能否知道 | 不知道 | 能算：应答人数 ÷ 总人数 |

比如试验中 Drug 组 60 人，有 27 人应答：

$$
\hat{p} = \frac{27}{60} = 45\%
$$

这个 45% 就是 TLF 里常见的 **ORR（Objective Response Rate，客观缓解率）**，用来估计真实的 p。换一批病人重做，可能是 42%，也可能是 48%。所以还要给它算一个 CI，比如 45%（95% CI：32%，58%）。

## 回到那段代码

```r
x <- rbinom(1, n, p)
```

这行模拟的是：**n 个病人，每人以概率 p 应答，数一数一共有几人应答。** 就像每个病人都抛一枚"不均匀的硬币"，正面朝上（应答）的概率是 p。

- `p = 0.05`：每个病人只有 5% 的机会应答，比如一个疗效很弱的药，或者一个罕见事件
- `p = 0.30`：每个病人有 30% 的机会应答

模拟时 p 由我们自己设定，所以能检查 CI 有没有套住它。现实中 p 不知道，这正是要做试验、算 CI 来估计它的原因。

**同样的思路也适用于不良事件。** 把"应答"换成"发生某种不良事件"，p 就变成**不良事件的发生概率**。AE 汇总表里的发生率，以及它的 CI，都是同样的计算方法。
=========================
简单说，**应答概率就是"一个病人用了药之后，病情好转达标的可能性"**。

## 用一个具体例子

假设有一种抗肿瘤药，规定"肿瘤缩小 30% 以上"就算**应答**。

- 给 100 个病人用这个药，最后有 40 个人的肿瘤缩小了 30% 以上
- 那么这个药的应答率大约是 **40%**

换个说法：**随便挑一个病人用这个药，他有大约 40% 的机会会应答。** 这个"40% 的机会"就是**应答概率**。

## 拿抛硬币来理解

| | 抛硬币 | 病人用药 |
|---|---|---|
| 每次的结果 | 正面 / 反面 | 应答 / 不应答 |
| 概率 | 正面的概率 = 50% | 应答的概率 = p |
| 例子 | 一枚均匀的硬币 | p = 40% 的药 |

每个病人就像抛一次硬币。只是这枚硬币不一定均匀，正面朝上（应答）的概率是 p。药效越好，p 越大。

## "概率"和"率"的区别

- **应答概率（p）**：药物**真实的**效果，是一个固定但不知道的数。
- **应答率（p̂）**：试验里**实际观察到的**比例，比如 60 人中 27 人应答，就是 45%。

试验的目的，就是用观察到的应答率去**估计**真实的应答概率。因为只观察了一部分病人，估计不一定准，所以要再加一个 CI，说明真实的应答概率大概在什么范围。

---

应答概率的英文是 **response probability**，也可以说 **probability of response**。

相关的几个说法：

| 中文 | 英文 | 说明 |
|---|---|---|
| 应答概率 | **response probability** / probability of response | 真实的 p，多用在统计方法、SAP 中 |
| 应答率 | **response rate** | 试验中观察到的比例 p̂，TLF 里最常见 |
| 客观缓解率 | **ORR**（Objective Response Rate） | 肿瘤试验的标准说法 |
| 应答者 | **responder** | 达到应答标准的病人 |
| 应答者分析 | **responder analysis** | 按应答 / 未应答做的分析 |

实际文档里，**response rate** 用得最多。即便统计上指的是真实概率，SAP 和 CSR 里通常也写作 "true response rate"。
