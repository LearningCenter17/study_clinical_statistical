：**计算 p 值，要先把结果变成一个"在 H₀ 下分布已知"的检验统计量，再去查那个分布的尾巴面积。** 标准正态是最常见的一种，但不是唯一的。

### 以 z 检验为例：三步

假设药物组比安慰剂组多降 **6 mmHg**，差值的 **SE = 2.5**，H₀ 是"真实差值 = 0"。

**第一步：标准化，得到检验统计量**

z = (观察值 − H₀ 下的值) / SE = (6 − 0) / 2.5 = **2.4**

意思是：观察到的差异相当于 2.4 个标准误。

**第二步：在标准正态下找尾巴面积**

双侧 p 值 = 两个尾巴（比 ±2.4 更极端）的面积之和：

```r
2 * pnorm(-2.4)   # 0.0164
```

```
           ╭───╮
         ╱       ╲
       ╱           ╲
  ░░  ╱             ╲  ░░   ← 两块阴影加起来 = 0.0164
 ─░┴─┴───────┬───────┴─┴░─
  −2.4       0       +2.4
```

**第三步：和 α 比较**

0.0164 < 0.05 → 显著。

### 标准化不是数学上必须的

其实不标准化也能算，直接在"H₀ 下差值的分布" N(0, 2.5²) 上找尾巴面积，结果完全一样：

```r
2 * pnorm(-6, mean = 0, sd = 2.5)   # 0.0164
```

标准化的好处是**统一**：不管原来是 mmHg、kg 还是天数，都换算成"几个 SE"，只用一张表、一套临界值（1.96）就能判断。这在没有电脑、靠查表的年代尤其重要，现在也让结果更容易比较和解释。

### 不同检验用不同的参照分布

思路都一样（构造统计量 → 查对应分布的尾巴），只是参照分布不同：

| 检验 | 检验统计量 | H₀ 下的分布 | R 求 p 值 |
|---|---|---|---|
| z 检验 | 估计值 / SE（σ 已知或大样本） | 标准正态 | `2*pnorm(-abs(z))` |
| t 检验 | 估计值 / SE（σ 用样本估计） | t 分布（df） | `2*pt(-abs(t), df)` |
| ANOVA / ANCOVA 的 F 检验 | 组间 / 组内变异 | F 分布（df₁, df₂） | `pf(F, df1, df2, lower.tail=FALSE)` |
| 卡方检验 | Σ(观察−期望)²/期望 | χ² 分布（df） | `pchisq(x, df, lower.tail=FALSE)` |

所以严格说，t 检验是把结果"标准化"成 t 分布，而不是标准正态；F 和 χ² 检验只看右尾，因为统计量只会是正数。

另外也有不依赖这类分布的方法，比如 **Fisher 精确检验**直接按组合概率算，**置换检验**用模拟构造 H₀ 下的分布，都不需要标准化。

**一句话：p 值 = 在 H₀ 成立时，得到"至少这么极端"结果的概率；标准化只是把结果放到一个已知分布上，方便算这个概率。**
