### 定义

**第二类错误（Type II error）= 放走坏人 / 漏诊**：H₀ 其实是假的，你却没能拒绝它。

放到临床里：**药其实有效，但试验结果不显著，你没能证明它有效。**

它发生的概率记作 **β**。与之对应的 **1 − β 就是检验效能（power）**：药真有效时，试验能成功检测出来的概率。

### 用火灾报警器理解

- 第一类错误：没着火，报警器响了（误报）
- 第二类错误：着火了，报警器没响（漏报）

### 什么决定了 β 的大小

β 不像 α 那样直接"设定"，而是由以下因素共同决定：

| 因素 | 怎样变化会让 β 变小（power 变大） |
|---|---|
| **真实效应大小** | 效应越大越容易发现（降 20 比降 2 好检测） |
| **个体变异 SD** | 病人反应越一致，越容易发现 |
| **样本量 n** | 越大越好，这是唯一能直接控制的 |
| **α** | 放宽 α 会降低 β，但会增加第一类错误，一般不动 |

回到 SE 那部分：效应大、SD 小、n 大，本质都是让"信号 / SE"变大，统计量更容易越过临界值。

### 临床中的意义

**1. 样本量计算的核心。** 试验设计时，统计师会根据预期效应和 SD，算出达到 **80% 或 90% power** 所需的样本量（即 β = 0.2 或 0.1）。你在 SAP 里看到的"以双侧 α = 0.05、90% power 检测出 X 的差异，需要每组 N 例"，说的就是这个。

**2. 后果主要是"错失"。** 一个有效的药被放弃，病人失去一个治疗选择，药企损失巨额研发投入。所以 β 的容忍度（10%–20%）比 α（5%，单侧 2.5%）宽松。

**3. 最重要的解读原则：不显著 ≠ 无效。**

p > 0.05 只说明"证据不足"，不能说明"没有差异"。可能药确实没用，也可能只是**样本量太小、power 不足**。这时应该看置信区间：

- CI 很窄且紧贴 0 → 即使有效应也很小
- CI 很宽（比如 −2 到 +15）→ 数据根本不足以下结论

这也是为什么要证明"差不多"，需要专门设计**等效或非劣效试验**，而不能拿一个不显著的优效试验来说事。

### 用 R 看 power 随样本量的变化

```r
set.seed(1)
# 药物真实效应 = 0.5 个 SD
power_at <- function(n) mean(replicate(5000,
  t.test(rnorm(n, 0.5), rnorm(n, 0))$p.value < 0.05))

sapply(c(20, 50, 86), power_at)
# ≈ 0.34  0.70  0.90   → n 越大，β 越小

power.t.test(delta = 0.5, sd = 1, power = 0.9)  # 理论计算：每组约 86 人
```

每组 20 人时，即便药真的有效，也有约 2/3 的概率得到"不显著"，这就是第二类错误。

**一句话：第二类错误就是"药有用，你却没发现"，β 是它的概率，1 − β 是 power，主要靠足够的样本量来控制。**
