这条评论是说我前面写的"非劣效设计时把 Δ 换成（真实差异 − M）"不严谨：**加 M 还是减 M，要看 M 的正负号约定和终点的方向（越高越好还是越低越好）**。最常见的写法是 M 取正数、终点越高越好，这时应该是 **真实差异 + M**。我之前的写法在这种约定下符号是错的。

最后提到的 "GOT-ni-hypothesis-direction" 应该是评论者附上的一个链接或条目名，我看不到具体内容，所以只按评论文字解释。

## 原理

样本量公式里的 Δ，本质是**真实差异与零假设边界之间的距离**。非劣效检验的零假设边界不是 0，而是 −M 或 +M。

**情况 1：越高越好（例如有效率、评分改善），M > 0**

- H₀：μ_T − μ_C ≤ −M（试验药比对照差 M 以上，即劣效）
- H₁：μ_T − μ_C > −M（非劣效）
- 真实差异为 δ，它到边界 −M 的距离是 δ − (−M) = **δ + M**

**情况 2：越低越好（例如不良事件率、疼痛评分），M > 0**

- H₀：μ_T − μ_C ≥ M
- H₁：μ_T − μ_C < M
- 距离是 **M − δ**

**情况 3：把 M 本身记为负数（例如直接写 M = −5 表示边界）**

- 这时距离是 **δ − M**，形式上就是我原来写的那样。

所以通用的写法是：**Δ = |真实差异 − H₀ 边界值|**，先把边界的位置定清楚，再计算距离。

## 符号写错的后果

用 σ = 10、单侧 α = 0.025、power = 90%，假设真实差异 δ = 2，M = 5（越高越好）：

| 写法 | Δ | 每组人数 |
|---|---|---|
| 正确：δ + M | 7 | 约 43 |
| 错误：δ − M | −3（平方后按 3 计算） | 约 234 |

公式中 n 与 1/Δ² 成正比，所以符号一错，人数相差好几倍。只有当 δ = 0 时，两种写法平方后结果相同，这时错误不会暴露出来，这也是这类错误容易被忽略的原因。

## 软件里怎么避免

在 SAS 中，直接把边界和方向写清楚，让软件自己算距离：

```sas
proc power;
  twosamplemeans test=diff
    nullmeandiff = -5      /* H0 边界：-M */
    meandiff     = 2       /* 真实差异 δ */
    sides        = U       /* 上侧检验：越高越好 */
    alpha        = 0.025
    stddev       = 10
    power        = 0.90
    npergroup    = .;
run;
```

如果终点越低越好，改成 `nullmeandiff = 5` 和 `sides = L`。

在 R 中，`power.t.test` 没有边界参数，要自己算好距离再传入：

```r
power.t.test(delta = 2 + 5, sd = 10, sig.level = 0.025,
             power = 0.9, alternative = "one.sided")
```

总结：这条评论的意思是我原来的写法只在 M 记为负数时才成立；在 M 取正、越高越好这种最常见的约定下，应该用 δ + M。
