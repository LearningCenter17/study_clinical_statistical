秩和检验的英文是 **rank-sum test**，最常见的全称是 **Wilcoxon rank-sum test**。

几个相关的叫法：

| 中文 | 英文 |
|---|---|
| 秩和检验 | rank-sum test |
| Wilcoxon 秩和检验 | Wilcoxon rank-sum test |
| Mann-Whitney U 检验 | Mann-Whitney U test |
| 合称 | Wilcoxon-Mann-Whitney test（WMW test） |
| 符号秩检验（配对） | Wilcoxon signed-rank test |
| 秩 | rank |
| 秩和 | rank sum / sum of ranks |
| 结（并列） | ties |

在 SAP 或 CSR 里，常见的写法是 "Wilcoxon rank-sum test"。SAS 里对应的是 `PROC NPAR1WAY` 加 `WILCOXON` 选项。
