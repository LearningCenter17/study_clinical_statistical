### 先说结论

**Power 计算就是在试验开始前回答一个问题："如果药真的有我预期的那么好，我招这么多人，有多大把握能把它证明出来？"**

反过来用更常见："要有 90% 的把握证明出来，我需要招多少人？"这就是**样本量计算**，两者是同一个计算的两个方向。

### 核心画面：两个钟形曲线

想象检验统计量（比如两组差值）的抽样分布，在两种"世界"里各长什么样：

```
     世界A：药无效(H₀)          世界B：药有效(H₁)，真实差值=δ
          ╭──╮                        ╭──╮
         ╱    ╲                      ╱    ╲
        ╱      ╲                    ╱░░░░░░╲
       ╱        ╲                  ╱░░░░░░░░╲
  ────╱──────────╲──────────┬─────╱░░░░░░░░░░╲────
      0                  临界值        δ
                     (超过它就判显著)
```

- 临界值由 **α** 决定（在世界A里，越过它的面积 = 第一类错误）
- **Power = 世界B的曲线落在临界值右边的面积**（阴影部分），即药真有效时，你得到显著结果的概率
- 落在左边的面积就是 **β**（第二类错误）

**两条曲线分得越开、各自越窄，power 越大。**
- 分得开：真实效应 δ 大
- 窄：SE 小，也就是 SD 小或 **n 大**

这就是 power 计算的全部本质：**调整 n，让两条曲线足够分开，使世界B有 80%–90% 落在临界值之外。**

### 需要输入什么

| 输入 | 含义 | 从哪来 |
|---|---|---|
| α | 第一类错误率 | 惯例：双侧 0.05 |
| 1−β | 目标 power | 惯例：80% 或 90% |
| δ | 预期的真实效应 | 既往研究、II 期数据、临床最小有意义差值（MCID） |
| σ | 个体变异 SD | 既往研究 |
| 输出 → n | 每组样本量 | |

### 手算一个例子

降压药，预期比安慰剂多降 **δ = 5 mmHg**，SD **σ = 10**，双侧 α = 0.05，power 90%。

两组均值比较的公式：

**n（每组）= 2 × (z₁₋α/₂ + z₁₋β)² × σ² / δ²**

- z₁₋α/₂ = 1.96（双侧 0.05 的临界值）
- z₁₋β = 1.28（90% power 对应的分位数）

n = 2 × (1.96 + 1.28)² × 10² / 5² = 2 × 10.5 × 4 ≈ **84 人/组**

公式直观含义：要求"信号 δ"至少比"噪音 SE"大 (1.96 + 1.28) ≈ 3.24 倍。1.96 用来越过临界值，1.28 保证世界B里 90% 的结果都在临界值之外。

几个关键规律：
- **δ 减半 → n 变 4 倍**（δ 在分母且是平方）。预期效应估得太乐观，试验就会严重 underpowered
- power 从 80% 提到 90%，n 约增加 1/3
- 实际还要按脱落率上调，比如预计脱落 10%，84 / 0.9 ≈ 94 人/组

R 验证：

```r
power.t.test(delta = 5, sd = 10, sig.level = 0.05, power = 0.9)
# n ≈ 85.03 per group
```

### 几个常见误区

**1. Power 是设计阶段的概念，不是对结果的描述。** 试验做完后再算"观察到的 power"（post-hoc power）基本没有意义，它只是 p 值的另一种写法。结果出来后应该看置信区间。

**2. Power 依赖于假设的 δ。** "90% power"的完整说法是"**如果**真实效应是 5 mmHg，有 90% 把握检测出来"。真实效应若只有 3，实际 power 会掉到约 44%。

**3. 不同终点公式不同。** 连续终点看 δ 和 σ；二分类终点看两组率（如 30% vs 45%）；生存终点看 HR，并且 power 取决于**事件数**而非总人数，所以生存试验常常是"等到发生 N 个事件"才分析。

**一句话：power 计算就是在动手前确认，你的试验规模足够大，大到真有效时不至于被噪音淹没。**
