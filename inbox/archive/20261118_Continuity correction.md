## 一句话解释

**用连续的分布（正态、卡方）去近似离散的计数时，做的一个"半格"修正。** 具体做法是把偏差 |O − E| 先减去 0.5，然后再参与计算。

## 为什么需要它

人数只能是整数：0、1、2、3……，是**一级一级的台阶**。而正态分布和卡方分布是**光滑的曲线**。拿光滑曲线去近似台阶，在边界上就会有误差。

可以把每个整数想象成一根**宽度为 1 的柱子**，比如"8"这根柱子实际上占据的是 7.5 到 8.5 这一段。如果要算"≥ 8"的概率，曲线下的面积应该从 **7.5** 开始算，而不是从 8 开始。如果从 8 开始，就漏掉了 8 号柱子的左半边。

这个"往外让半格"的修正就叫连续性校正。

## 一个直观的例子：抛硬币

抛 10 次硬币，问正面 ≥ 8 次的概率是多少？

**精确答案**（二项分布直接算）：

```
P(X ≥ 8) = (45 + 10 + 1) / 1024 = 0.0547
```

**用正态近似**：均值 = 5，标准差 = √2.5 ≈ 1.58

| 方法 | 计算 | 结果 |
|---|---|---|
| 不校正 | P(Z ≥ (8 − 5)/1.58) = P(Z ≥ 1.90) | 0.029 ❌ 差了近一半 |
| 校正 | P(Z ≥ (7.5 − 5)/1.58) = P(Z ≥ 1.58) | **0.057** ✅ 接近 0.0547 |

样本小的时候，不校正会明显**低估 p 值**，让结果看起来比实际更显著。

## 用在卡方检验上：Yates 校正

对 2×2 表的卡方检验做连续性校正，叫做 **Yates 校正**（Yates' continuity correction），公式是：

```
                (|O − E| − 0.5)²
χ²_Yates  =  Σ  ────────────────
                      E
```

用头痛的例子（偏差 |O − E| = 7.5）：

| | 偏差 | χ² | p 值 |
|---|---|---|---|
| 不校正 | 7.5 | 5.88 | 0.015 |
| Yates 校正 | 7.5 − 0.5 = **7.0** | **5.12** | **0.024** |

校正后 χ² 变小，p 值变大，结论更**保守**。

CMH 也有同样的校正：分子从 [Σ(aₖ − Eₖ)]² 改为 (|Σ(aₖ − Eₖ)| − 0.5)²。

## 要不要用？

这一点统计学界一直有争议：

- **支持用的观点**：样本小时可以避免 p 值被低估，防止假阳性。
- **反对用的观点**：Yates 校正往往**矫枉过正**，p 值偏大、检验效能偏低。而且样本真小的时候，**直接用 Fisher 精确检验更好**，不需要靠近似加修正。样本大的时候，校正与否几乎没有区别。

现在比较主流的做法是：**样本够大就用不校正的 Pearson 卡方，样本小就用 Fisher 精确检验**，Yates 校正用得越来越少。临床试验里具体用哪个，以 SAP 的规定为准。

## 实际编程要注意：SAS 和 R 的默认值不同

做 R 和 SAS 双编程交叉核对（QC）时，这里是一个**常见的结果对不上的原因**：

| | 默认是否校正 | 怎么改 |
|---|---|---|
| R `chisq.test()` | **默认校正**（2×2 表时） | `correct = FALSE` 关掉 |
| R `mantelhaen.test()` | **默认校正** | `correct = FALSE` 关掉 |
| R `prop.test()` | **默认校正** | `correct = FALSE` 关掉 |
| SAS `PROC FREQ /CHISQ` | 两个都输出 | 读 "Chi-Square" 行是不校正的；"Continuity Adj. Chi-Square" 行是校正的 |
| SAS `PROC FREQ /CMH` | **不校正** | — |

所以如果 SAS 的 CMH p 值和 R 的对不上，第一件事就是检查 R 有没有加 `correct = FALSE`。

连续性校正只有一个使用场景：**把离散的计数结果，用连续分布（正态或卡方）去近似的时候。** 只要满足这一条，原则上就可以加校正。

## 常见的使用场景

**1. 2×2 卡方检验（Yates 校正）**

就是前面讲的情况。注意只用于 **2×2 表**（自由度 = 1）。更大的表（比如 3×2）一般不做校正，R 的 `chisq.test()` 对大表也不会自动加。

**2. CMH 检验**

分层的 2×2 表，原理相同。

**3. 两个比率的比较（z 检验）**

比如比较两组应答率，用正态近似：

```
z = (|p₁ − p₂| − 校正项) / SE
```

它和 2×2 卡方检验等价，所以校正方式也对应。

**4. 单个比率的检验和置信区间**

比如"应答率是否高于 30%"，或者计算应答率的 95% 置信区间：
- 用正态近似的 **Wald 区间**可以加校正，每端往外扩 1/(2n)
- **Wilson 区间**也有带校正的版本
- **差值的置信区间**（比如两组应答率之差的 95% CI）同样可以加校正

这在疗效 TLF 里非常常见。

**5. McNemar 检验（配对数据）**

比如同一批病人治疗前后是否应答：

```
χ² = (|b − c| − 1)² / (b + c)
```

b、c 是"前后结果不一致"的两个格子。注意这里减的是 **1** 而不是 0.5，因为统计量是基于两个计数的差。

**6. 非参数检验的正态近似**

比如 **Wilcoxon 秩和检验**、**符号秩检验**。样本较大时会用正态近似算 p 值，秩和也是离散的，所以也会加 0.5 校正。

**7. 样本量计算**

方案里根据应答率计算样本量时，有的公式（比如 Fleiss 公式）有带校正的版本，算出来的样本量会稍大一些。

## 不需要校正的情况

| 方法 | 原因 |
|---|---|
| Fisher 精确检验 | 直接用精确的离散分布计算，不做近似 |
| 精确二项检验 / Clopper-Pearson 区间 | 同上 |
| t 检验、ANCOVA | 数据本来就是连续的 |
| Log-rank、Cox 回归 | 不是基于这种计数近似 |
| 大于 2×2 的卡方检验 | 通常不做 |

## 在 TLF 里会碰到的地方

| TLF | 可能涉及的方法 |
|---|---|
| 二分类疗效终点表（如 ACR20 应答率） | 应答率的 95% CI、组间差值的 95% CI、CMH p 值 |
| 配对比较（如治疗前后转阴） | McNemar 检验 |
| 非参数分析（如评分数据） | Wilcoxon 检验 |
| 方案 / SAP 的样本量部分 | 带或不带校正的样本量公式 |

## SAS 和 R 的默认设置（双编程核对时很重要）

| 方法 | R 默认 | SAS 默认 |
|---|---|---|
| 2×2 卡方 | `chisq.test()` **校正** | `PROC FREQ /CHISQ` 校正和不校正**都输出** |
| CMH | `mantelhaen.test()` **校正** | `/CMH` **不校正** |
| 两比率比较 | `prop.test()` **校正** | — |
| 比率置信区间 | `prop.test()` 的 CI **校正**；`binom.test()` 是精确法 | `BINOMIAL` 默认 Wald **不校正**，要校正加 `BINOMIAL(CORRECT)` |
| 率差置信区间 | — | `RISKDIFF` 默认**不校正**，要校正加 `RISKDIFF(CORRECT)` |
| McNemar | `mcnemar.test()` **校正** | `/AGREE` **不校正** |
| Wilcoxon | `wilcox.test()` **校正**（使用正态近似时） | `PROC NPAR1WAY` **校正**，要关掉加 `CORRECT=NO` |

可以看出一个规律：**R 的默认值大多是校正的，SAS 的大多是不校正的**（NPAR1WAY 是例外）。所以 R 和 SAS 结果对不上时，先检查校正选项是否一致，再对照 SAP 里规定的是哪一种。
