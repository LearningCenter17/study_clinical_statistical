# 常用统计检验方法与临床示例

---

## 一、连续变量（近似正态分布）

### 1. 独立样本 t 检验（Student's t-test）
**适用：** 两组独立样本，连续变量，近似正态，方差齐（方差不齐时用 Welch t 检验，R 默认就是 Welch）。

**临床例子：**
一项降压药 II 期 RCT，受试者随机分为**试验药组**和**安慰剂组**，主要终点是第 12 周收缩压（SBP）相对基线的变化值。

- H₀：两组 SBP 平均变化相同
- H₁：两组 SBP 平均变化不同
- 结果示例：试验组 −12.3 mmHg，安慰剂组 −4.1 mmHg，p < 0.001

```r
t.test(CHG ~ TRT01P, data = adbp_wk12, var.equal = FALSE)  # Welch
```

> 补充：同一受试者给药前后比较（如基线和第 12 周），用**配对 t 检验**（`paired = TRUE`）。

### 2. 方差分析（ANOVA）
**适用：** 三组及以上独立样本，连续变量，近似正态，方差齐。

**临床例子：**
剂量探索研究，受试者分为**安慰剂、10 mg、20 mg、40 mg** 四组，比较第 24 周 HbA1c 变化值。

- H₀：四组均值全部相等
- 若整体 p < 0.05，只能说明"至少有一组不同"，需要做**事后多重比较**（如 Dunnett 检验，各剂量组分别对比安慰剂）

```r
fit <- aov(CHG ~ TRT01P, data = adlb_hba1c)
summary(fit)
# 各剂量 vs 安慰剂
library(multcomp)
summary(glht(fit, linfct = mcp(TRT01P = "Dunnett")))
```

> 实际注册试验中更常用 **ANCOVA**（把基线值作为协变量）或 **MMRM**（重复测量），但单因素 ANOVA 是它们的基础。

## 二、分类变量 / 计数数据

### 3. 卡方检验（Chi-square test）
**适用：** 两个分类变量是否关联；样本量较大，**每个格子的期望频数 ≥ 5**。

**临床例子：**
抗感染药物试验，比较**试验药组**与**对照药组**的临床治愈率。

| | 治愈 | 未治愈 | 合计 |
|---|---|---|---|
| 试验药 | 168 | 32 | 200 |
| 对照药 | 146 | 54 | 200 |

- 治愈率 84% vs 73%，卡方检验 p ≈ 0.007

```r
tab <- matrix(c(168, 32, 146, 54), nrow = 2, byrow = TRUE)
chisq.test(tab, correct = FALSE)
```

> 实际分析中如果有分层因素（如中心、疾病严重程度），通常用 **CMH 检验**（`mantelhaen.test()`）。

### 4. Fisher 确切概率法（Fisher's exact test）
**适用：** 2×2（或 R×C）表，**样本量小或任一格子期望频数 < 5** 时代替卡方检验。

**临床例子：**
罕见病研究中比较两组**严重不良事件（SAE）**发生情况，样本量很小：

| | 发生 SAE | 未发生 | 合计 |
|---|---|---|---|
| 试验组 | 5 | 15 | 20 |
| 安慰剂组 | 1 | 19 | 20 |

- 有格子期望频数 = 3 < 5，卡方检验不可靠，改用 Fisher，p ≈ 0.18

```r
fisher.test(matrix(c(5, 15, 1, 19), nrow = 2, byrow = TRUE))
```

> 安全性 TLF 中，AE 按 SOC/PT 汇总的组间比较经常用 Fisher，因为很多 PT 的发生例数很少。

## 三、非参数检验（不满足正态，或为等级 / 有序数据）

### 5. Mann-Whitney U 检验（Wilcoxon 秩和检验）
**适用：** 两组独立样本；数据严重偏态、有离群值、样本量小，或为有序等级数据。比较的是**分布 / 中位数位置**。

**临床例子：**
比较两种术后镇痛方案的**住院天数**。住院天数通常右偏（大多数 3–5 天，少数并发症患者 20+ 天）。

- 方案 A 中位数 4 天（IQR 3–6），方案 B 中位数 6 天（IQR 4–9），p = 0.02
- 报告时用**中位数和 IQR**，而不是均值±SD

```r
wilcox.test(LOS ~ TRT, data = adhosp)
```

> 另一个常见场景：疼痛 VAS 评分、改良 Rankin 量表（mRS）等**有序评分**。

### 6. Kruskal-Wallis 检验
**适用：** 三组及以上独立样本的非参数比较，相当于 ANOVA 的非参数版本。

**临床例子：**
比较**轻度、中度、重度** COPD 患者的血清炎症标志物 IL-6 水平。生物标志物数据通常严重右偏。

- 若整体 p < 0.05，再做两两比较（如 **Dunn 检验**，并做 Bonferroni / Holm 校正）

```r
kruskal.test(AVAL ~ SEVERITY, data = adbm_il6)
# 事后两两比较
library(FSA)
dunnTest(AVAL ~ SEVERITY, data = adbm_il6, method = "holm")
```

## 快速选择表

| 数据类型 | 两组 | 多组（≥3） | 配对 / 重复测量 |
|---|---|---|---|
| 连续 · 正态 | t 检验 | ANOVA | 配对 t 检验 / 重复测量 ANOVA / MMRM |
| 连续 · 非正态 / 等级 | Mann-Whitney U | Kruskal-Wallis | Wilcoxon 符号秩检验 / Friedman |
| 分类 · 大样本 | 卡方检验 | 卡方检验（R×C） | McNemar 检验 |
| 分类 · 小样本 | Fisher 确切检验 | Fisher（R×C） | 精确 McNemar |

**判断正态性的实用建议：** 不要只看 Shapiro-Wilk 的 p 值（大样本时几乎总是显著）。结合 Q-Q 图、直方图和偏度一起判断；另外，样本量较大时（每组 n > 30–50），t 检验对轻度偏态比较稳健。最后，注册试验的检验方法应当**在 SAP 中预先指定**，而不是看完数据后再挑选。
