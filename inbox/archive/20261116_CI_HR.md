HR的CI
理解 HR 的关键只有一句话：**对 HR 取 log 之后，它就和你已经理解的"差值"一模一样了。**

## 1. 为什么要取 log

HR（hazard ratio，风险比）是一个比值，有三个麻烦：

- 无效值是 **1**，不是 0
- 取值范围是 (0, ∞)，左右不对称：HR=0.5 和 HR=2 的效应大小相同，但离 1 的距离不一样
- 抽样分布是偏的，不接近正态

取 log 之后：

- log(HR) = log(h₁) − log(h₀)，**本身就是一个差值**
- 无效值变成 **0**
- 取值范围是 (−∞, +∞)，左右对称：log(0.5) = −0.69，log(2) = +0.69
- 抽样分布近似正态

所以 Cox 模型里直接估计的是 **β = log(HR)**，以及它的标准误 **SE(β)**。

## 2. CI 的计算：在 log 尺度上算，再取指数还原

和均值差的思路完全一样，只是多了最后一步 exp：

1. 在 log 尺度上：β ± 1.96 × SE(β)
2. 两端取 exp，得到 HR 的 CI

例子：β = −0.3285，SE = 0.109

- log 尺度：−0.3285 ± 1.96 × 0.109 → (−0.543, −0.115)
- 取 exp 后：**HR = 0.72，95% CI (0.58, 0.89)**

注意这个 CI 不以 0.72 为中心：0.72 − 0.58 = 0.14，而 0.89 − 0.72 = 0.17。**HR 的 CI 本来就是不对称的**，因为它在 log 尺度上才是对称的。TLF 做 QC 时，这一点可以当作检查依据：算出 log(下限)、log(HR)、log(上限)，三者应该是等距的。

## 3. P 值

**Wald 检验**（Cox 模型自带）：
z = β / SE = −0.3285 / 0.109 ≈ −3.0，查正态分布得 p ≈ 0.003

逻辑和均值差的检验一样：估计值离 0 有几个 SE。

**Log-rank 检验**（临床报告里更常用）：
它不估计 HR，只检验两组生存曲线是否相同。在每个事件时间点，比较每组"实际发生的事件数"和"如果两组没差别、预期会发生的事件数"，然后把所有时间点加总。

所以 TLF 里常见的组合是：**p 值来自（分层）log-rank 检验，HR 和 CI 来自（分层）Cox 模型**。两者用的方法不同，偶尔会出现 p 略大于 0.05、但 CI 刚好不包含 1 的情况，这是正常的。SAP 一般会写明各自用哪个方法。

## 4. HR 本身是什么意思

hazard 指"在时间 t 还没发生事件的人当中，下一瞬间发生事件的速率"。

HR = 0.72 的意思是：在**任何时间点**，治疗组仍处于风险中的人发生事件的瞬时速率，是对照组的 72%。

"任何时间点"这个说法背后就是**比例风险假设**：HR 被假定不随时间变化。如果两条 KM 曲线交叉，这个假设就站不住了，单个 HR 的解释力会下降。

## 5. 一个很有用的直觉：SE 由事件数决定

对于 1:1 随机分组：

> **SE(log HR) ≈ 2 / √D**，其中 D = 总事件数

和均值差不同，这里的精度**几乎只取决于发生了多少事件**，与入组人数关系不大。入组 1000 人、只有 50 个事件，CI 依然会很宽。这也是生存分析的样本量计算其实是在算"需要多少事件"、以及很多试验采用事件驱动（event-driven）设计的原因。

## 对应到 R

```r
fit <- coxph(Surv(AVAL, 1 - CNSR) ~ TRT01P + strata(STRAT1), data = adtte)
summary(fit)
# coef      = β = log(HR)
# exp(coef) = HR
# se(coef)  = SE
# lower .95 / upper .95 = HR 的 CI（已经取过 exp）
# Pr(>|z|)  = Wald p 值

survdiff(Surv(AVAL, 1 - CNSR) ~ TRT01P + strata(STRAT1), data = adtte)  # 分层 log-rank 检验
```

（ADTTE 中 CNSR = 1 表示删失，所以事件指示变量是 `1 - CNSR`。）
