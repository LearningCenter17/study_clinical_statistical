这是一个**二分类终点、2:1 不等比例分配**的样本量计算。结果是：**安慰剂组 42 人，药物组 84 人，共 126 人；考虑 15% 脱落后，安慰剂组 50 人，药物组 100 人，共 150 人。**

## 各参数的含义

| 参数 | 含义 |
|---|---|
| **ASAS40** | 中轴型脊柱关节炎（包括强直性脊柱炎）试验中常用的主要终点。它是一个**应答指标**：患者在 ASAS 评估的 4 个方面中，至少 3 个改善 ≥ 40%（并且绝对值改善至少 2 分），其余方面没有恶化，就算"应答"。所以终点是二分类的（应答 / 不应答） |
| **20% vs 45%** | 预期 ASAS40 应答率：安慰剂组 20%，药物组 45%，差 25 个百分点 |
| **双侧 α = 0.05** | I 类错误，z₀.₉₇₅ = 1.96 |
| **把握度 80%** | z₀.₈ = 0.8416 |
| **placebo : drug = 1 : 2** | 药物组人数是安慰剂组的 2 倍，k = 2 |
| **脱落率 15%** | 算出的人数要再除以 0.85 |

## 计算

二分类终点、不等比例分配的公式：

$$n_{\text{pbo}} = \frac{\left[z_{1-\alpha/2}\sqrt{\bar p(1-\bar p)\left(1+\frac{1}{k}\right)} + z_{1-\beta}\sqrt{p_1(1-p_1) + \frac{p_2(1-p_2)}{k}}\right]^2}{(p_2 - p_1)^2}$$

**第 1 步：加权平均率**

$$\bar p = \frac{p_1 + k\,p_2}{1+k} = \frac{0.20 + 2 \times 0.45}{3} = 0.3667$$

**第 2 步：分子的两部分**

- 第一部分：1.96 × √(0.3667 × 0.6333 × 1.5) = 1.96 × 0.5902 = **1.1568**
- 第二部分：0.8416 × √(0.20 × 0.80 + 0.45 × 0.55 / 2) = 0.8416 × √0.28375 = 0.8416 × 0.5327 = **0.4483**

**第 3 步：代入公式**

$$n_{\text{pbo}} = \frac{(1.1568 + 0.4483)^2}{0.25^2} = \frac{2.5763}{0.0625} = 41.22$$

向上取整为 **42**。我逐个代入人数核算了把握度：41 人时为 79.8%，42 人时为 80.8%，所以 42 是满足 80% 的最小人数。

**第 4 步：药物组和总人数**

- 安慰剂组 42 人，药物组 42 × 2 = 84 人，共 **126 人**

**第 5 步：考虑脱落**

- 安慰剂组：42 / 0.85 = 49.4，取 **50**
- 药物组：50 × 2 = **100**
- 共 **150 人**

## 汇总

| | 安慰剂组 | 药物组 | 总人数 |
|---|---|---|---|
| 可评价人数 | 42 | 84 | 126 |
| 考虑 15% 脱落后的入组人数 | 50 | 100 | **150** |

## 另一种算法：连续性校正

有些方案会使用**带连续性校正的公式**（Fleiss 校正），结果更保守：安慰剂组约 48 人，药物组 96 人，共 144 人；考虑脱落后约 57 + 114 = 171 人。用哪种算法应该在方案中写明，以免核对时出现不同的数字。

## SAS 代码

```sas
proc power;
  twosamplefreq test=pchi
    groupproportions = (0.20 0.45)   /* 安慰剂组, 药物组 */
    groupweights     = (1 2)
    alpha            = 0.05
    sides            = 2
    power            = 0.80
    ntotal           = .;
run;
```

结果应该在 126 人左右。SAS 会自动把总人数取整为符合 1:2 比例的数。

## R 代码

R 自带的 `power.prop.test` 只支持 1:1 分配，可以用下面的函数：

```r
n_2prop <- function(p1, p2, k = 2, alpha = 0.05, power = 0.80) {
  za <- qnorm(1 - alpha/2); zb <- qnorm(power)
  pb <- (p1 + k*p2) / (1 + k)
  n1 <- (za*sqrt(pb*(1-pb)*(1 + 1/k)) +
         zb*sqrt(p1*(1-p1) + p2*(1-p2)/k))^2 / (p2 - p1)^2
  n1 <- ceiling(n1)
  c(placebo = n1, drug = k*n1, total = n1*(1 + k))
}

n <- n_2prop(0.20, 0.45)          # 42, 84, 126
pbo <- ceiling(n["placebo"] / 0.85)
c(placebo = pbo, drug = 2*pbo, total = 3*pbo)   # 50, 100, 150
```
