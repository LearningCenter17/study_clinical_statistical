这条意见也对。前面说"窄说明样本量充足、宽说明不确定性大"，把 CI 宽度只归到了样本量上，说得不完整。

## CI 宽度由什么决定

| 因素 | 影响 |
|---|---|
| **数据的变异**（SD） | SD 越大，CI 越宽 |
| **样本量 n** | n 越大，CI 越窄（按 1/√n 缩小） |
| **置信水平** | 99% 比 95% 宽 |
| **分析方法** | 比如 ANCOVA 调整基线后，残差变异变小，CI 更窄 |
| **比例本身的大小**（率类终点） | p 接近 50% 时 CI 最宽，接近 0 或 1 时更窄 |
| **事件数**（生存终点） | **起决定作用的是事件数，不是入组人数** |

所以 CI 窄，可能是因为样本量大，也可能是因为数据本身变异小。不能直接推出"样本量够了"。

## 生存终点：看事件数

Cox 模型中，log(HR) 的标准误大约是：

$$
SE(\log \widehat{HR}) \approx \frac{2}{\sqrt{D}}
$$

D 是两组**合计的事件数**，前提是 1:1 随机。公式里根本没有入组人数 n，只有 D。

原因是：删失的病人只贡献"到某个时间点还没发生事件"这一点信息，真正决定 HR 估计精度的，是观察到了多少个事件。

## R 例子：同样的 HR，不同的事件数

```r
hr_ci <- function(hr, D) {
  se <- 2 / sqrt(D)
  round(exp(log(hr) + c(-1, 1) * qnorm(0.975) * se), 2)
}

hr_ci(0.70, D = 30)     # 约 (0.34, 1.43)  很宽，含 1
hr_ci(0.70, D = 100)    # 约 (0.47, 1.04)  仍含 1
hr_ci(0.70, D = 300)    # 约 (0.56, 0.88)  不含 1
```

比较两个假设的试验：

| | 试验 A | 试验 B |
|---|---|---|
| 入组人数 | 1000 | 300 |
| 事件数 | 30（随访短、事件少） | 150 |
| HR 的 CI | **宽** | **窄** |

试验 A 人多，CI 反而更宽。这就是肿瘤试验的 SAP 里，期中分析和最终分析的时间点都是按**事件数**触发的（比如"观察到 200 个 PFS 事件时进行最终分析"），而不是按入组人数或日历时间。

## 再补充一点：窄 CI 不等于结论可靠

CI 只反映**随机误差**，不反映**系统偏倚**：

- 如果数据有偏倚，比如大量缺失、揭盲、人群选择有问题，CI 可以很窄，但中心位置是偏的。
- CI 窄也不代表效果有**临床意义**。样本量很大时，一个很小的差值也可能得到一个很窄、不含 0 的 CI，统计上显著，但临床上未必重要。

所以解读 CI 时要分开看：**中心位置**说明效应有多大，**宽度**说明估计有多精确，再结合研究设计和数据质量判断结论是否可信。
